# ФойдаБот v2 — Ўзбекистон учун Telegram MVP

## Нима учун шу модел?
- Ўзбекистонда Telegram бизнес ва харид жараёнларида кенг ишлатилади; АҚШ савдо вазирлигининг мамлакат бўйича қўлланмасида Telegram энг оммабоп мессенжер экани қайд этилган.
- Кичик бизнесларни рақамлаштиришда соддалик, ишонч ва фойдаланувчига тушунтириб бериш муҳим. Шу сабаб MVP аввал аниқ кундалик вазифани ҳал қилади.
- Халқаро messaging-commerce тажрибаси мижозларга таниш чат интерфейси орқали хизмат кўрсатишга асосланади.

## Ҳозирги функциялар
- Кирим ва чиқимни қайд этиш
- Баланс ва сўнгги операциялар
- CSV ҳисоботни юклаб олиш
- Ўзбек тилида меню
- Маълумотларни SQLite'да сақлаш

## Ўрнатиш
1. Telegram'да `@BotFather` орқали `/newbot` қилиб бот яратинг.
2. Токенни махфий сақланг.
3. Python 3.10+ ўрнатинг.
4. Терминалда:
   ```bash
   python -m venv .venv
   # Windows:
   .venv\Scripts\activate
   # macOS/Linux:
   source .venv/bin/activate
   pip install -r requirements.txt
   ```
5. Windows PowerShell:
   ```powershell
   $env:TELEGRAM_BOT_TOKEN="BOTFATHER_TOKEN"
   python bot.py
   ```
   macOS/Linux:
   ```bash
   export TELEGRAM_BOT_TOKEN="BOTFATHER_TOKEN"
   python bot.py
   ```

## Ривожлантириш режаси
### 1-босқич — талабни текшириш
20–50 киши билан синаш, қайси функцияни ҳафтасига бир неча марта ишлатишини ўлчаш, фикр-мулоҳаза йиғиш.

### 2-босқич — кундалик қиймат
- ойлик категориялар бўйича таҳлил;
- тўлов/қарз эслатмалари;
- оилавий ёки кичик бизнес режими;
- админ учун фойдаланиш статистикаси;
- ўзбек лотин/кирилл тил танлови.

### 3-босқич — монетизация
- Бепул тариф: асосий ҳисоб-китоб;
- Premium: кенгайтирилган ҳисобот, экспорт ва бир нечта ҳисоб;
- кичик бизнес тарифи;
- ҳамкорлик таклифлари, фақат очиқ ва фойдаланувчи розилиги билан.

Тўловларни ишга туширишдан олдин расмий merchant аккаунти ва Payme/Click каби провайдернинг амалдаги талаблари бўйича интеграция қилинади. Карта маълумотларини ботда сақламанг. Аввалги босқичда тўлов қабул қилиш ўчирилган.

## Муҳим чекловлар
- Бу код ишга тушириш мумкин бўлган MVP; бот ҳали хостингга жойланмаган.
- Компьютер ёпилса, бот тўхтайди. 24/7 ишлаш учун VPS/хостинг ва қайта ишга тушириш сиёсати керак.
- Даромад кафолатланмайди. Аввал фойдаланувчи эҳтиёжи ва тўлашга тайёрлигини текширинг.
- Реал ишлатишдан олдин махфийлик сиёсати, маълумотларни ўчириш функцияси, захира нусха ва хавфсизлик текшируви қўшилиши керак.


## Railway орқали 24/7 ишга тушириш (қўлда жойлаштириш)
1. Кодни ўзингизнинг шахсий GitHub репозиториянгизга юкланг. `.env`, токен ва `.db` файлларини репозиторияга қўшманг.
2. Railway аккаунтида янги project яратинг ва GitHub репозиториясини deploy қилинг.
3. Variables бўлимида `TELEGRAM_BOT_TOKEN` қийматини қўшинг (токенни фақат шу ерга киритинг).
4. `Procfile` worker сифатида `python bot.py` ни ишга туширишни кўрсатади. Агар Railway сервисни веб-сервис деб аниқласа, service start command'ни `python bot.py` қилиб, worker/background service турини танланг.
5. Муҳим: SQLite файли доимий дискда бўлмаса redeploy/restart пайтида маълумот йўқолиши мумкин. Production учун persistent volume ёки PostgreSQL миграцияси керак. Бу MVP учун аввал тест маълумотлар билан синаб кўринг.
6. Deploy log'да `ФойдаБот ишлаяпти...` кўринса, Telegram'да ўз ботингизни очиб `/start` юборинг.

Railway нархи ва тарифлари ўзгариши мумкин; ишга туширишдан олдин расмий тарифларни текширинг. Хостингга жойлаштириш автоматик бажарилмаган — бу қадамларни аккаунтингизда ўзингиз тасдиқлашингиз керак.
